# GUILDA INVASORES

Nova interface do painel da guilda, com Dashboard, Membros, Lines, Administração e Ajustes.

A autenticação do Supabase foi mantida. Nesta primeira versão, os dados de membros/lines da interface são de demonstração e ficam em memória no navegador; o próximo passo é conectar essas telas às tabelas reais do Supabase.
